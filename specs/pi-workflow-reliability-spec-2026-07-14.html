Scope

In scope

  • Canonical identity and causal controls
  • Pause, resume, retry, stop, and nudge
  • Declared worktree execution
  • Schema migration, locks, leases, and takeover
  • Bounded model surfaces and event-only completion

Non-goals

  • A new workflow language
  • Loops, conditions, or dynamic fan-out
  • Distributed execution across machines
  • Automatic model selection
  • Production deployment
  • Inferred or synthetic TTFB

The project directory chooses the durable state namespace; the declared execution directory chooses where every child runs. Relative node directories are resolved beneath it, while .. and symlink escapes are rejected.
